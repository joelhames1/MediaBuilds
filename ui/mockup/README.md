# Cuesheet mockup

Clickable front-end mockup for songvid, built on the demo song's real lyrics, word timing, sections and shots.
Everything else (jobs, Claude's replies, costs) is scripted. Open `index.html` through a local server
(`python3 -m http.server -d ui/mockup`) so the video and stills load.

Rates shown on the Picture step are illustrative, not provider pricing.
